# PROJECT REPORT
# Retail Sales Data Visualization & Storytelling

## Objectives
- Transform raw data into charts, graphs and a dashboard.
- Use Python, Pandas, NumPy and Matplotlib.
- Create visuals that reveal trends and comparisons clearly.
- Build a business-focused data story.
- Create a portfolio-ready project.

## Visualizations
1. Monthly Sales Trend
2. Sales by Category
3. Sales by Region
4. Monthly Profit Trend
5. Sales vs Profit
6. Sales by Payment Method
7. Top 10 Products
8. Customer Segment Sales
9. Category vs Region Heatmap
10. Sales Distribution

## Dashboard
The `05_dashboard/retail_sales_dashboard.png` file combines KPIs and key charts into one management view.

## Conclusion
The project demonstrates how raw retail records can be transformed into visual insights that support business decisions. Future scope includes rebuilding the dashboard in Tableau or Power BI and adding interactive filters and forecasting.
