# Data Visualization Internship Project

**Retail Sales Data Visualization & Storytelling**

This project transforms a retail dataset into processed data, 10 actual graph images, a dashboard and a data story.

## Structure
```text
📁 data-visualization-internship-project
├── 01_data/retail_sales_raw.csv
├── 02_visualization/analysis.py
├── 02_visualization/requirements.txt
├── 03_processed_data/
├── 04_charts/ (10 PNG graphs)
├── 05_dashboard/retail_sales_dashboard.png
├── DATA_STORY.md
├── PROJECT_REPORT.md
└── README.md
```

## Run
`pip install -r 02_visualization/requirements.txt`
`python 02_visualization/analysis.py`

## Skills
Data transformation, data visualization, dashboard design, data storytelling, trend analysis, business insights, Python, Pandas and Matplotlib.
